Kyungdong University Global — Project Overview

Website (React) + CMS Backend (PHP/MySQL) — One-page summary
Frontend: kdu-global-website · Backend: C:\xampp\htdocs\kdu-backend · Doc date: 31 Jul 2026 · Full docs: docs/KDU-Global-Project-Documentation.docx

1. What this project is

Public university website + CMS so admins, HODs, faculty, and club leads update content without developers.

  • Frontend: React 19, Vite 6, React Router 7 — localhost:5173
  • Backend: PHP 8 + MySQL (kdu_backend) — /kdu-backend/public
  • Dev proxy: /api & /media → XAMPP backend
  • Only published CMS content appears on the live site

5. Key workflows

  • Site content: Root → Website content → Publish → refresh site
  • Department: HOD edits pages/news/events → publish
  • Faculty: one profile; tick multiple departments + Graduate
  • Clubs: Root creates club → creates Club Admin → admin publishes club

9. Troubleshooting

  • Published but site unchanged → hard-refresh; check /api/site/content has values
  • Broken images → use Upload (not long XAMPP paths); keep faculty photos out of site hero
  • MySQL error 2002 → start MySQL in XAMPP
  • Faculty missing on 2nd department → save affiliations + publish profile
